# 日本专家第二意见

日本专家第二意见是本知识库的总入口。目标不是寻找“更先进”或“更昂贵”的治疗，而是在关键医疗决策节点检查诊断依据、治疗顺序、替代路径和执行可行性。

## 更适合考虑的情况

- 新确诊但对病理、分期或一线方案存在疑问；
- 不同医疗机构建议明显不同；
- 被告知不能手术或只能姑息治疗，希望理解依据；
- 治疗后复发、转移或疑似耐药；
- 病理类型罕见、原发部位不明或长期无法明确诊断；
- 基因报告出现罕见变异，但不知道是否真正影响治疗；
- 希望了解日本的获批治疗或临床试验是否匹配。

## 通常重新评估什么？

1. 病理诊断和免疫组化是否充分；
2. 影像分期、病灶范围和进展模式；
3. 手术、药物与放疗的先后顺序；
4. 是否需要重新活检、病理复核或分子检测；
5. 现有方案的证据、获益、风险和替代方案；
6. 日本建议能否在患者所在地执行；
7. 是否确有必要赴日面诊或治疗。

## 不适合等待书面意见的情况

病情快速恶化或出现急症时，应优先在所在地医院处理。资料严重不足、问题不明确，或者现有治疗稳定且没有新的决策节点时，也未必需要立即会诊。

## 建议资料

- 病理报告及必要时的切片或数字病理；
- CT、MRI、PET-CT原始DICOM影像；
- 手术、药物和放疗完整时间线；
- 疗效评估及近期检验；
- 基因检测原始报告；
- 当前症状、体力状态和合并疾病；
- 3至5个希望专家明确回答的问题。

## 结果如何使用？

二次会诊可能确认原方案，也可能建议补充检查、调整治疗顺序或提供备选方案。患者应与所在地治疗团队讨论证据、风险、费用及可执行性。

第二意见不保证改变方案，也不等于必须赴日。
